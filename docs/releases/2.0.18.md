# Patty 2.0.18

## Changes

- Unified session and command search, keyboard navigation, and focus restoration.
- A quiet workbench with on-demand notifications and session details, a top-left sidebar toggle, consistent sidebar rows, rounded terminal surfaces, and Windows Mica with a solid fallback.
- Windows attention notifications with native activation, cold startup, and selection of the target workspace and split terminal.
- PowerShell 5.1 and PowerShell 7 command state, exit codes, and elapsed time in session details.
- OSC 7501 program status on local and SSH output, with bounded records, progress, Hook priority, attention navigation, and Windows delivery.
- Ordered local terminal output with consumption acknowledgments, bounded outstanding bytes, shared background parsing, and precise Windows batch deadlines.
- Updated boot-background assertions for the current neutral themes, restoring backend test execution without color exclusions.

## Limits

Normal Shell input latency under a 30-session background workload has not consistently met the target of at most 16 milliseconds above the same run's idle latency. Existing measurements do not justify claiming that target is complete.

SSH program metadata is supported. The local output backpressure and shared parsing scheduler have not been extended to SSH. Command integration is verified for PowerShell 5.1 and PowerShell 7. Other shells do not yet provide equivalent command results.

Application restart restores layouts and starts new shell processes. It does not keep commands alive, restore scrollback, or resume an AI conversation. AI resume, history, and draft features remain deferred.

This release uses the existing per-user NSIS installation and application identity. Updating an installation requires closing Patty and its terminal processes. New CLI integrations apply after restarting the affected CLI.
