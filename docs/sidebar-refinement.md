## 依据

用户在 2026-11-03 的截图中指出 Agent 动画消失、collection 与终端行高不一致，以及应用区域配色仍不理想。

- `c50d635` 删除了 SessionItem 对 ContributionGrid 的引用，动画组件本身仍在仓库。当前组件测试还明确要求前后台工作均不显示动画，需要一起修正。

本机窗口当前被 Computer Use 识别为 ChatGPT。其[使用限制](C:/Users/29218/.codex/plugins/cache/openai-bundled/computer-use/26.1027.51404/docs/guidance.md)写明 “Do not automate the ChatGPT desktop app UI”，因此没有操作或捕获该窗口。官方公开资料作为本次参考。

## 1. 目标

恢复可辨识的 Agent 工作动画；统一列表节奏；让中性的应用区域衬托终端内容。

验收条件：

- Claude、OpenCode、Codex、OMP、Qwen、Copilot 的 working 状态使用各自已有动画色。选中与未选中行均显示，其他状态保持静态。
- 动画集中在行右侧，不遮挡名称和关闭操作；减少动态效果时停止绘制；隐藏、销毁后释放调度；切换主题时使用新颜色。
- collection、单行终端、双行终端均为 48px 高。重命名、展开折叠、关闭、键盘导航不受影响。
- 应用顶栏与侧栏保持连续背景；浅色应用区域采用 `#f3f3f3`，深色采用 `#202020`。选中行采用灰色，强调色用于焦点和明确操作。
- 终端区域继续不透明并保留圆角、细边界与短阴影。Mica 模式的统一主题遮罩从 35% 调整为 70%，保留原有实色回退。
- 深浅色、160/264/320px 侧栏、左右布局、窄窗口和减少动态效果均通过实际浏览器验证。记录真实截图与检查结果。

## 2. 非目标

## 3. 受影响模块

- SessionItem：恢复工作动画及其状态条件。
- ContributionGrid 与调度验证：处理减少动态效果、主题变化及组件生命周期。
- Sidebar.module.css：共享行高和右侧动画范围。
- 内置 light/dark 主题与 App.module.css：中性应用底色、选中背景、Mica 遮罩。
- 组件测试、主题验证和 workbench 浏览器场景：验证实际行为、尺寸和像素变化。

三项分别提交，均不涉及持久化格式或数据迁移。可分别使用普通 revert 回退对应提交；不使用重置分支或覆盖用户改动。
