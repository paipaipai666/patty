# Patty Logo

## Files

| File | Format | Description |
|------|--------|-------------|
| patty-icon.svg | SVG | Indigo sidebar and terminal prompt icon, with vector outlines |
| patty-icon.ico | ICO | Windows icon with 16, 20, 24, 32, 40, 48, 64, 128, and 256px frames |

## Usage

The SVG file can be used for documentation and web contexts:

```markdown
![Patty Logo](logo/patty-icon.svg)
```

The same ICO file is copied to `resources/icon.ico` for the Windows application
and installer, and to `src/renderer/public/icon.ico` for the frontend favicon.

The startup splash uses the same sidebar, prompt, and cursor geometry.
